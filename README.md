# Python Car Rental System

This is a simple car rental program I made while practicing Python. The idea was to have a list of cars that someone could rent, return, or check for availability.

I wanted to get more comfortable working with dictionaries, functions, loops, and user input, so I put those concepts together into one program.

## Project dates

- **Original file:** `carrental.py`
- **Last modified locally:** November 18, 2025 (based on the file information I saved)
- **Published to GitHub:** October 23, 2026

The local date is a *last modified* timestamp, not a confirmed original creation date.

## What it does

- Shows which cars are available and their daily rental prices
- Lets someone choose a car and how many days they want to rent it
- Calculates the rental cost based on the number of days
- Marks a car as unavailable once it's rented
- Lets someone return a car and makes it available again

## What I used

- Python
- Dictionaries to store the cars, prices, and availability
- Functions to separate the different actions
- If/else statements to check user choices
- A while loop to keep the menu running

## How to run it

You'll need Python installed. Download the `car_rental.py` file and run:

```bash
python car_rental.py
```
